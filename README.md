# Drilling Fluid Alkalinity Dataset

This repository contains the dataset used in the study:

**"Development of Data-Driven Models for Estimating Mud and Filtrate Alkalinity Using Machine Learning Applications"**

Authors: A. Onder, S. Gul, and B. Kulga

## Dataset Description

The dataset contains 1,138 cleaned drilling-fluid records used for the development and evaluation of machine learning models for estimating mud and filtrate alkalinity parameters (Mf, Pf, and Pm).

The data were derived from daily drilling-fluid reports collected from multiple wells and include drilling-fluid properties and alkalinity measurements used in the machine learning framework.

## Data Processing

The original database consisted of approximately 1,600 daily drilling-fluid reports. Following data extraction, quality control, removal of incomplete and duplicate records, outlier assessment, and physical-consistency checks, 1,138 records were retained for modeling.

## Purpose

The dataset is provided to support transparency, reproducibility, and further research on machine learning applications for drilling-fluid alkalinity estimation.
